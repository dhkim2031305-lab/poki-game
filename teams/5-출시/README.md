# 출시팀

## 파트
| 파트 | 하는 일 | 문서 |
|---|---|---|
| 스토어 자료 | 사이트별 썸네일, 제목, 설명, 태그, 조작법 문구 | `store/` |
| 제출·운영 | 사이트별 계정·업로드·심사 기록, 업데이트 이력, 독점 조건 확인 | `release-log.md`, `platforms.md` |

## 맡는 일
- 사이트별 **제출 요구사항**(썸네일 크기, 글자 수, 필수 항목)을 각 개발자 포털에서 확인해 `platforms.md`에 적어요. 사실 확인은 Gemini 웹 검색으로 하고, 확인한 날짜와 출처를 같이 남겨요. **기억으로 채우지 않아요.**
- 설명 문구는 Claude가 한국어·영어로 쓰고, 마지막 말투 손질도 Claude가 해요.
- 썸네일 이미지는 GPT로 만들고, Claude가 사이트별 크기에 맞게 줄여서 `store/<사이트>/`에 넣어요.
- 실제 업로드는 **사용자가** 해요. 출시팀은 체크리스트와 자료를 준비하고 결과를 기록해요.

## 완료 기준
- [ ] 올릴 사이트마다 `platforms.md` 요구사항이 확인됨 (날짜·출처 포함)
- [ ] `store/<사이트>/`에 썸네일과 `listing.md`가 준비됨
- [ ] QA 통과한 `dist/<사이트>.zip` 업로드 → `release-log.md` 기록
