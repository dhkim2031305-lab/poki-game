# 사이트별 용량 기준 — "양보단 질" 지키면서 올리기 (출시팀 · 2026-11-28)

> 요청: 팀장 (사용자 "나는 퀄리티가 좋은게 좋아요 양보단 질이에요" · 스킬 그림 크게 다시 → ZIP 30MB 넘을 수 있음, 지금 18.4MB)
> 확인 방법: 출처 페이지를 직접 내려받아 원문 대조 (Claude)

## 1. 사이트별 상한·권장

| 사이트 | 전체 상한 | 첫 다운로드 | 파일 수 | 근거 |
|---|---|---|---|---|
| **CrazyGames** | **250MB** | **50MB 이하 필수**, **모바일 홈은 20MB 이하** | 1,500개 | [C3] |
| **GameDistribution** | 확인 안 됨 (문서에 MB 숫자 없음) | 확인 안 됨 | 확인 안 됨 | [G1] "smooth performance" 만 |
| **itch.io** | 압축 풀어 **500MB**, 한 파일 **200MB** | 규정 없음 | 1,000개 | [I1] |
| Poki (참고, 대상 아님) | 권장 **8MB** | 권장 **5MB** | — | [P10] (엔진 안내 글의 권장) |

### ⭐ CrazyGames "첫 다운로드"는 ZIP 크기가 아니에요
> "When the SDK is integrated…, the initial download size is measured between the start of loading and the occurence of the first Gameplay start event… This event should be triggered when the user enters in a playable state, so excludes menus and additional loading steps." [C3]
>
> "In case the SDK is not integrated, total file size is used" [C3]

→ **첫 `gameplayStart` 전까지 내려받은 양**만 세요. 그 뒤에 불러오는 건 첫 다운로드에 안 들어가요. 즉 **ZIP이 30MB여도, 첫 판 시작 전까지 20MB 아래로 받으면 모바일 홈 조건을 지킬 수 있어요.** (SDK를 꼭 붙여야 해요 — 우리는 이미 붙어 있어요.)

## 2. 질을 지키는 방법 [제안 → 개발·디자인]

| # | 방법 | 질 영향 | 효과 |
|---|---|---|---|
| 1 | **고른 나라 것만 먼저 불러오기**: 첫 화면·나라 고르기에는 작은 그림만, 나라를 고르면 그 나라 장수·스킬 2개 큰 그림만 받고 `gameplayStart`. 나머지 29개국 큰 그림은 **필요할 때(그 나라를 고를 때)** 받기 | 없음 (그림은 그대로 큼) | 첫 다운로드가 나라 수에 상관없이 작아요. **가장 큰 효과** |
| 2 | **기기에 맞춰 두 벌**: 큰 그림(512/384)과 절반 그림(256/192)을 둘 다 넣고, 화면 배율(DPR)이 1이거나 메모리가 작은 기기는 절반 그림을 받아요 | 고해상도 폰·PC는 그대로 최고 화질 | 저사양 폰 다운로드·메모리 절반. CrazyGames도 iOS·저메모리 기기는 DPR 1로 돌려요 [C3] |
| 3 | **WebP 품질 맞추기**: 스킬 그림은 품질 85 안팎 + 알파 유지. 무손실(lossless)은 피하기 | 눈으로 거의 차이 없음 (디자인팀 나란히 비교로 확인) | 보통 30~50% 줄어요 (실측 필요) |
| 4 | 가장자리 투명 영역 잘라내기(칸 여백만 줄이기) | 없음 | 파일·메모리 조금 줄어요 |

### ⚠️ "사이트판만 화질 낮추기"는 추천하지 않아요
- GameDistribution 약관 2.6.4: GD 버전은 다른 곳에 올린 **최신 버전과 같아야** 해요. 사이트마다 그림 화질이 다르면 이 조항과 부딪힐 수 있어요.
- 그래서 **모든 사이트에 같은 그림**을 넣고, 차이는 위 1·2번처럼 **"언제 받느냐"와 "어떤 기기냐"**로만 둬요. 사이트마다 다른 건 SDK 코드뿐이에요(지금처럼).

## 3. 올릴 때 기준 (출시팀 체크)

| 항목 | 기준 | 재는 법 |
|---|---|---|
| ZIP 전체 | **250MB 이하** (CrazyGames) · 목표는 **50MB 이하** (로딩 체감) [제안] | `ls -la dist/*.zip`, 압축 풀어서 크기 |
| 파일 수 | **1,000개 이하** (itch.io가 가장 엄격) | `unzip -l dist/web.zip \| tail -1` |
| 한 파일 | 200MB 이하 (itch.io) | — |
| **첫 다운로드** | **20MB 이하** (CrazyGames 모바일 홈) · 50MB는 반드시 | 헤드리스 브라우저로 첫 `gameplayStart`까지 받은 바이트 합계 (QA·개발 테스트로 만들기 [제안]) |
| 첫 판까지 시간 | 20초 이하 (CrazyGames가 외부 파일을 볼 때 쓰는 기준) · Poki는 "10초 넘으면 떠나요" | 느린 4G 흉내로 측정 |

## 4. 지금 상태
- 2026-11-28 시험판 v2 `web.zip` 약 18.4MB (팀장 측정). 첫 다운로드는 아직 안 쟀어요 → 개발·QA에 측정 부탁.
- 스킬 그림을 크게 바꿔 ZIP이 30MB가 되어도 **1번(고른 나라만 먼저)**을 하면 CrazyGames 기준 안에 들어갈 가능성이 커요.
