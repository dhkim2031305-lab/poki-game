# 출시·업데이트 기록

## 업로드 체크리스트 (사용자가 직접 올려요 · 2026-11-26 초안)

> 순서 [제안 · 사용자 "일단 대기"(2026-11-26)]: **① itch.io → ② GameDistribution → ③ CrazyGames**
> - itch.io는 심사가 없어서 먼저 올리고, 실제 폰(안드로이드·아이폰)에서 확인하는 시험장으로 써요.
> - GameDistribution은 심사가 길어서(최대 1~3주) 일찍 넣어요.
> - CrazyGames는 심사가 가장 까다로워서(영어·광고·품질) 앞의 두 곳에서 문제를 고친 뒤 넣어요.
> - 모든 사이트에 **같은 버전**을 올려요(GameDistribution 약관 2.6.4). 업데이트도 같이 해요.

### 0. 올리기 전 (모든 사이트)
- [ ] QA 최종 통과 (`teams/4-QA/`) — 실제 폰 fps·아이폰 사파리·갤럭시 확인 포함
- [ ] **18개 언어 번역 완료** (사용자 결정 2026-11-26: 번역 뒤 출시) · 원어민 확인
- [ ] `npm run build` → `dist/<사이트>.zip` 새로 만들기 (사이트마다 다른 ZIP이에요)
- [ ] 썸네일·커버 준비 (`store/thumbnail-지시서.md` → `store/<사이트>/`)
- [ ] 이 표 맨 아래 "기록"에 날짜·버전(커밋 번호)을 적기

### ① itch.io (사용자가 할 일)
> 화면 메뉴 이름은 올릴 때 실제 화면에서 확인해요 (공식 문서로 확인한 건 Mobile Friendly·Fullscreen button·언어 고르기·용량 제한).
- [ ] 계정 만들기 (itch.io 가입)
- [ ] 새 프로젝트 만들기 → 종류 **HTML** → 파일 `dist/web.zip` 올리고 브라우저에서 플레이하도록 표시
- [ ] 임베드 설정: 크기 **1280×720** [제안] · **Mobile Friendly 체크** · **Fullscreen button 체크**
- [ ] 제목·짧은 설명·설명·장르·태그: `store/사이트별-등록표.md` itch.io 칸
- [ ] Languages: **번역 끝난 언어만**
- [ ] 커버 630×500 · 스크린샷 3~5장
- [ ] 먼저 비공개로 저장 → 폰 두 대(안드로이드·아이폰)로 열어 보고 → 공개
- [ ] 결과(주소)를 출시팀에 알려 주기

### ② GameDistribution (사용자가 할 일)
- [ ] 개발자 계정 만들기: gamedistribution.com → Developers → Sign up (지급 정보: 100유로부터 지급)
- [ ] 대시보드에서 새 게임 만들기 → **gameId 복사**
- [ ] gameId를 개발팀에 전달 → 개발팀이 `platforms.config.json`에 넣고 `npm run build` 다시 (사용자가 직접 넣어도 돼요)
- [ ] `dist/gamedistribution.zip` 올리기
- [ ] 보상형 광고 사용 체크 (개발자 패널의 rewarded 항목)
- [ ] 제목·설명(424자)·조작법(358자)·장르 2개·태그 5개·연령대: `store/사이트별-등록표.md`
- [ ] 언어: 번역 끝난 언어만 체크
- [ ] 썸네일 JPG 512×384 · 512×512 · 200×120 (+1280×720 · 1280×550)
- [ ] 심사 제출 (최대 1~3주) → 결과를 출시팀에 알려 주기

### ③ CrazyGames (사용자가 할 일)
- [ ] 개발자 계정 만들기: developer.crazygames.com → Sign up
- [ ] 약관 확인: **2개월 독점(보상 +50%)은 고르지 않기** (사용자 확정 2026-11-26 "추천방식대로 진행해") — 다른 사이트에도 올리기 때문
- [ ] 새 게임 제출 → `dist/crazygames.zip` 올리기
- [ ] 방향: **가로만** · 기기: 데스크톱 + 모바일
- [ ] **"Progress Save" 토글 켜기** (국가 금고 저장 · 안 켜면 Data 모듈이 꺼져요, `save-progress.md`)
- [ ] 제목·설명·조작법·태그: `store/사이트별-등록표.md`
- [ ] 커버 1920×1080 · 800×1200 · 800×800 + 미리보기 영상(가로·세로, 15~20초)
- [ ] Basic Launch 심사 → 결과 → (통과하면) Full Launch 심사
- [ ] 반려되면 사유 원문을 출시팀에 그대로 붙여 주기 (특히 파산 이어하기 광고 관련)
