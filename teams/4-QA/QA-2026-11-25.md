- 돌진·범위의 배율은 표와 같아요. 예: 룩셈부르크1 0.9(무적 0.98초), 네덜란드1 0.9(앞 4번 ÷8 + 마지막 0.4), 덴마크2 1.0(0.6+0.4), 독일2 0.5+0.5, 스페인1 첫 마리 1.6·나머지 0.3, 이스라엘2 0.4+0.4, 폴란드1 0.62→0.81→0.95(뒤일수록 셈), 일본1 0.5+0.5, 콜롬비아2 0.5+0.4.

### 7. 사이트별 ZIP (`test/sdk.js`: 빌드한 ZIP을 풀어 가짜 SDK로 실행)
- 크기: 4개 모두 약 7.6MB(10MB 이하). ZIP 맨 위에 `index.html`이 있어요. 바깥 링크는 SDK 주소뿐이에요.
- Poki: gameLoadingFinished → gameplayStart → (ESC) Stop/Start → 쓰러짐 Stop → rewardedBreak → Start → 클리어 Stop → 다음 판 Start. 판 사이 광고는 보상형을 본 판에서 한 번 건너뛰고, 그다음 클리어 다시하기에서 commercialBreak가 나와요. 순서가 맞아요.
- CrazyGames: init → loadingStart → loadingStop → gameplayStart/Stop, requestAd rewarded·midgame. 통과.
- GameDistribution: showAd rewarded·interstitial, SDK_GAME_PAUSE/START. 통과(gameId는 아직 비어 있어요).
- 일반 웹: 광고보기 버튼이 숨겨져요.
- 광고 중에는 **소리가 꺼지고(무음) 입력도 막혀요**(D를 눌러도 장수 x 그대로). 광고가 끝나면 소리가 돌아와요.
- SDK를 막으면(광고 차단) 4개 모두 광고 버튼 없이 진행돼요. 콘솔 에러는 브라우저의 "리소스 못 불러옴" 1줄뿐이에요.
- 기록: 판이 끝나면 `aw.best`에 저장되고, 새로고침 뒤에도 남아요. 저장소가 막혀도(시크릿 모드 흉내) 에러 없이 진행돼요.
