# Codex 작업10 — 스킬에서 기본공격 모양이 나가는 것 빼기 (사용자 지시 2026-11-27)

사용자: "스킬을 날렸는데 기초에 시안했던(기본공격) 게 나가서 문제. 미국 장수 보면 스킬이 나가야 되는데 기존 기본공격이 나가잖아."
예: 미국1(Lantern Signal Ricochet)은 G.shots에 기본 무기 투사체(kind=무기 기본 총알·도끼·streak·sling 등, HERO_SHOT 모양 포함)를 쏴서 평타와 똑같이 보여요.

src/game.js만 고쳐요. 판정·피해·속도·튕김·관통 등 수치와 동작은 그대로, **모양만** 바꿔요.

## 할 일
1. 60개 스킬(30개국×1·2)을 전부 훑어, 쓰는 동안 기본공격 모양이 나오는 곳을 표로 찾아요:
   - skill:true 인 G.shots 투사체를 기본 무기 kind/HERO_SHOT 모양으로 그리는 곳
   - 스킬 중 h.swing / 기본 검기(BASIC_TRAIL·나라별 검기 시안 #8)·기본 총구 섬광·기본 화살/투척 모양을 그대로 쓰는 곳
2. 스킬 투사체는 그 스킬 대표 그림 `skill/u/<나라>-<n>`(이미 로드됨, UI.img)로 그려요: 진행 방향으로 회전, 크기 약 40~56px(sh.big 있으면 곱), 스킬 색 SKILL_COL 얇은 꼬리(기본공격 꼬리 아님, 0.12초 이하). 그림이 없으면 SKILL_COL 두 색 원판(테두리 1.5px)으로 대체 — 기본 무기 모양으로 떨어지지 않게.
3. 스킬 중 기본 휘두르기 검기·기본 트레일이 나오면 스킬 쪽(castPose·skill art)만 남기고 기본 것은 그리지 않아요. 기본공격(skill 아님)은 전혀 바꾸지 않아요.
4. 3D 모드(render3d / R3D.proj로 2D 덮개)에서도 같은 그림.
