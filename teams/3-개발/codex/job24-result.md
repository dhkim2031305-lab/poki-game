# 작업 24 결과

천자총통 설치 무적 0.1초가 끝나면 탑승한 상태로 기본 치기와 활 쏘기를 할 수 있습니다. 기본 공격 중에도 화포는 예정된 6발을 모두 발사합니다.

| 변경 위치 | 반영 내용 |
|---|---|
| `src/game.js` · 탑승 좌표와 장수 렌더링 | 발사 반동, 발사 프레임의 위치 보정, 이동 덜컹임을 장수 좌표에서 제거했습니다. 설치 중과 탑승 중에는 장수의 시전·걷기·대기 흔들림을 생략하고 기본 공격 동작을 표시합니다. |
| `src/game.js` · 화포 | 이동 덜컹임을 제거하고 발사 시 포신 프레임과 화포 몸체의 4px 반동을 유지했습니다. 발사 시 1px, 마지막 포탄 착탄 시 3px 화면 흔들림도 유지했습니다. |
| `src/game.js` · 입력과 기본 공격 | 설치가 끝나면 공격 잠금을 해제합니다. 치기 판정과 화살은 탑승 위치에서 시작합니다. 스킬 입력 기억과 다른 스킬 시전 시 하차 규칙을 유지했습니다. |

`node --check src/game.js`와 `git diff --check`를 통과했습니다. Node VM에서 설치 직후 잠금 해제, 반동 중 탑승 좌표 고정, 이동 시 탑승 위치, 탑승 중 화살 출발점, 6발의 발사·착탄 시각과 피해·판정 반경, 화면 흔들림 값을 확인했습니다. 실제 브라우저의 화면과 입력은 확인하지 못했습니다.
