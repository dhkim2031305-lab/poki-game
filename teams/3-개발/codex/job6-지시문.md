## 1) 스킬 시전 중 무적 (GDD 0-20 9) · 사용자 "스킬동안의 체력이 안 단다는 거로만, 공격속도 늘리는 건 없어요")
- 스킬 버튼을 누른 순간부터 **장수의 시전 동작이 끝날 때까지**(돌진은 달리는 동안, 연사는 쏘는 동안 포함) 체력이 닳지 않아요. 날아간 화살·포탄·연결체 비행·장판 지속 시간은 **포함 안 함**.
- 무적 버튼(`useInvuln`, `h.skillT`/`boostT`, 공속 2.5배)과 **따로**. 공속 2.5배·무적 표시 링·무적 버튼 횟수는 건드리지 않아요.
- 피격 판정의 기존 무적 경로(`h.inv` 쪽, `hurt` 등)에 합쳐요. 사망·광고 상태와 겹치지 않게(죽은 상태엔 적용 안 함).
- 룩셈부르크 1 "돌진 무적 1초"(`dashInv`)·헝가리 2 "맞힐 때마다 +0.2초"는 그대로 유지(긴 쪽이 이김).
- 표시: 무적 버튼 링은 쓰지 않고, 시전 무적 동안 장수 테두리를 아주 은은하게 밝게(알파 0.25 정도의 흰 외곽선) — 최소로.
- 시전 동작 끝 = `h.cast`가 끝나는 순간(돌진은 `h.dash` 끝 + 복귀, 연사는 `h.barrage` 끝)으로 잡아요.

## 2) 한국 스킬 시전감 수정 (사용자 "GPT 안대로", 화포 2배 추가안은 뺌)
자료: `teams/3-개발/review-4/skill-feel/codex-korea-feel.md` 2절(+3절 조작감). 시간은 아래 확정값 그대로:
- **거북선 돌격**: 0–0.08 몸 낮춤·발 디딤 → 0.08–0.22 철갑 조각 맞물림·용머리 들림(밝은 테 윤곽) → 0.22–0.28 제자리 버팀(용 입 연기만) → **0.28 출발**(짧은 북 소리는 기존 효과음 재사용, 진행 방향 1px 카메라 킥) → 끝 연기(2px 흔들림, 명중 시 0.03초 히트스톱) → 복귀.
- **천자총통 포격**: 0–0.10 환도로 목표 가리킴·화포가 장수 뒤에서 솟음 → 0.10–0.32 바퀴 딛고 신호 자세·심지 0.22초 타들어감(포신 윗면·바퀴 테 밝게) → **발사 0.32 / 0.52 / 0.72**(매번 반동·포구 연기·1px 흔들림) → 각 0.40초 비행 → 착탄(0.72 / 0.92 / 1.12), **마지막만** 3px 흔들림 + 0.03초 히트스톱 → **0.78** 자세 풀고 평타 잠금 해제(+0.3초 규칙은 그대로), 화포 0.92–1.07 사라짐. **화포 크기는 지금 그대로.**
- 둘 다: 누른 첫 프레임에 바로 반응(자세 시작). 준비 중 보호는 위 1)의 시전 무적으로(슈퍼아머 안 씀).
- **취소 시 횟수 반환**: 거북선 준비 0.08초 안, 화포 첫 발사 전에 스킬이 취소되면(사망 등 기존 취소 경로) 횟수를 돌려줘요 — 기존 `skillDebit` 규칙 안에서.
- 대표 그림·연속 그림·자세 칸 쓰는 방식은 지금 그대로.
