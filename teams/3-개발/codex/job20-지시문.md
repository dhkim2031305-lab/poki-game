# Codex 작업20 — 3D만 남기고 2D 모드 없애기 (사용자 직접 지시 2026-11-28: "3d로만 게임 진행할꺼니까 2d는 없애버리세요")

작업 트리(작업15~19 포함) 위에 이어서. src/game.js · src/render3d.js · src/fx.js · tools/build-single.js 등 개발 파일만. 피해·판정·시간표는 그대로.

## 할 일
1. 렌더러 선택 제거: `use3d`(23줄 근처)는 항상 3D. `?render=2d` 주소, `settings.render`, 미리보기 2D/3D 비교 버튼(build-single `#rt` 등)을 지워요.
2. **2D 모드 전용 그리기 경로 삭제**: use3d가 false일 때만 쓰이던 코드(2D 바닥·벽·방 그리기, 2D 전용 캐릭터/외계인/소품 배치, `if (!use3d)` 가지, 2D 전용 상수·함수)를 지워요. 3D에서도 쓰는 2D 캔버스 겹치기(HUD·말풍선·조준 원·아직 3D 장면에 안 들어간 스킬 효과 그림 등)는 **지우지 말고 유지**해요 — 지우면 3D 화면에서 안 보이게 돼요. 확실하지 않으면 남기고 결과에 적어요.
3. WebGL을 못 쓰는 기기: 게임 대신 짧은 안내 화면(영어+그 나라 언어 아님, 영어 한 줄: "This game needs WebGL (3D). Please try another browser or device.")을 보여 줘요. 2D로 대신 돌리지 않아요. i18n 키 ui.nowebgl 추가(en/ko만, ko "이 게임은 3D(WebGL)가 필요해요. 다른 브라우저나 기기에서 열어 주세요.").
4. 테스트·도구에서 2D를 가정한 곳(예: teams/3-개발/test/*.js 중 render=2d 쓰는 것)은 목록만 결과에 적어요(고치지 않음).
5. SETUP.md에 "렌더러: 3D만(2026-11-28 사용자 결정), WebGL 없으면 안내 화면" 한 줄.
