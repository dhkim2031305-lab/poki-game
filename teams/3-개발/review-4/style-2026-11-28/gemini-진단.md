### 2. 어울리는 이펙트 스타일 기준 (디자이너 작업 수치)

| 항목 | 제작 기준 및 권장 수치 | 적용 가이드 |
| :--- | :--- | :--- |
| **합성 방식** | **Normal(70%) + Additive(30%)** | 실체는 불투명(Normal)하게 잡고, 외곽 발광부만 약한 가산(Screen/Add)으로 처리 |
| **팔레트 규칙** | **채도(S) 65~80% / 명도(V) 75~90%** | 형광 100% 금지. 바닥 던전(저채도 회색)과 대비되는 **명도 차이**로 시인성 확보 |
| **외곽선·질감** | **1~2px 뚜렷한 외곽선 + 단순 단색 셀채색** | 미세 그라데이션·실사 브러시 제거. 캐릭터 스프라이트 픽셀 밀도(128×128 이하) 준수 |
| **크기 비율** | **캐릭터 키(H) 대비 1.5 ~ 2.2배 이내** | 최대 직경 90~110px 제한. 체코 수레처럼 화면의 1/3을 덮는 과대 크기 금지 |
| **바닥 원근** | **Y축 스케일 0.55 고정 (`scaleY: 0.55`)** | 바닥에 깔리는 마법진/파동은 쿼터뷰 타원 비율로 납작하게 눌러 배치 |
| **지속 시간** | **총 0.25초 ~ 0.35초 (15~20프레임)** | **발생 0.05초(순간 폭발) $\rightarrow$ 유지 0.1초 $\rightarrow$ 소멸 0.15초(소멸)**. 0.9초 잔상 완전 제거 |

### 4. 1개국 프로토타입 시험 순서 (추천: 덴마크 `06-2`)

가장 구조가 단순한 **덴마크(06-2, 회전 참격)**로 기준 모델을 먼저 확립하는 것을 추천합니다.

1. **[코드 튜닝] 지속 시간 단축**: 전체 재생 시간을 0.9초에서 **0.3초**로 줄이고, 뒤 0.1초 동안 알파가 급격히 사라지게 조정 (잔상 문제 즉시 해결 검증).
2. **[코드 튜닝] 쿼터뷰 투영**: 이펙트 컨테이너에 `transform: scale(1.0, 0.55)`를 적용하여 바닥 타일과 동일한 각도로 눕힘.
3. **[합성 조정] 블렌드 모드 변경**: `lighter` 대신 `source-over`(Normal)로 그리고, 안쪽 코어는 불투명(Alpha 1.0), 외곽 테두리만 약한 발광으로 렌더링.
4. **[인게임 검증]**: 어두운 돌바닥 및 외계인 피격 모션과 0.3초 동안 깔끔하게 치고 빠지는 타격감 확인 후, 나머지 29개국으로 가이드 일괄 배포.
