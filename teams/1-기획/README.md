# 기획팀

## 파트
| 파트 | 하는 일 | 문서 |
|---|---|---|
| 핵심 기획 | 조작, 목표, 끝나는 조건, 한 판 흐름 | `GDD.md` |
| 레벨·밸런스 | 속도·간격·난이도 곡선 수치 | `balance.md` |
| 수익화 | 광고 위치, 보상형 광고 규칙 | `monetization.md` |

순서: 핵심 기획 → (승인) → 레벨·밸런스 + 수익화

## 맡는 일
- 사용자가 준 아이디어를 **기획서(`GDD.md`)**로 정리해요.
- 빈칸은 무난한 값으로 채우되 `[제안]` 표시를 붙여서 사용자가 고를 수 있게 해요.
- 아이디어를 **바꾸거나 새로 만들지 않아요.** 사용자가 원할 때만 Gemini로 두 번째 의견을 받아요.

## 산출물
- `GDD.md` — 게임 기획서 (유일한 기준 문서)
- `balance.md` — 수치, `monetization.md` — 광고 규칙
- `작업기록.md` — 날짜별 기록

## 완료 기준 (다음 팀으로 넘기는 조건)
- [ ] GDD의 필수 칸(1~7) 다 채워짐
- [ ] `[제안]` 표시가 모두 사용자 확인을 받음
- [ ] 사용자가 "기획 확정"이라고 승인함 → `STATUS.md` 단계를 ② 디자인으로
