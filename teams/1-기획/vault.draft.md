# 국가 금고 (영구 성장) — 초안 (2026-11-27 · 전부 [제안])

> 사용자 결정 (팀장 세션, 사용자가 고른 이유): "국가 금고를 넣으면 '모으면 결국 깰 수 있다'가 돼서 (하위권 나라 클리어 불가가 포털 심사에서 차별로 보일) 위험도 같이 줄어요"
> 근거: `review/gemini-추가요소-2026-11-27.md` ① 1번 · `review/gpt-리뷰-2026-11-27.md`
> ⚠️ 바뀌는 원칙: GDD 0-4의 사용자 원문 "어차피 가난한 나라로는 못깨게" → 이제 **"한 번에는 못 깨지만, 모으면 결국 깬다"**가 돼요. 풍자는 "부자 나라는 첫 판에, 돈 없는 나라는 N판 모아서"로 바꿔 살려요.

## 먼저 알아 둘 점 — 16~30위가 못 깨는 진짜 이유
- 16~30위는 **싸움이 약해서가 아니라 돈 규칙 때문에** 파산해요 (라운드마다 −7.5, 6라운드 시작 때 돈이 0 이하).
- 그래서 금고에 **"시작 자본"** 강화가 꼭 있어야 해요. 공격력·체력만 올려서는 파산을 못 피해요.
- 2~15위는 파산은 안 하지만 6라운드가 어려워요 → 공격력·체력 강화가 도움이 돼요.

## ① 쌓이는 방식
- **나라별 금고 (추천)**: 그 나라로 한 판마다 그 나라 금고에 쌓여요.
  - 좋은 점: "그 나라로 노력해서 출발선을 산다"는 풍자가 살아요. 1위로 모아서 30위를 쉽게 여는 꼼수가 없어요.
  - 다른 안 — 공통 금고: 어느 나라로 모아도 같이 써요. 빠르지만 1위로 모아 다른 나라를 다 여는 길이 생겨요.
- 쌓이는 양 (판이 끝날 때, 파산·실패·클리어 모두):
  - **도달한 라운드 × 1** + **처치 수 × 0.05** (금고 단위는 게임의 "돈"과 같아요)
  - 예: 30위 콜롬비아가 2라운드 파산, 처치 25 → 2 + 1.25 = **약 3**
  - 6라운드 클리어하면 **+5** 더 (클리어 보너스)

## ② 쓰는 곳 — 강화 4가지 (나라마다 따로)
| 강화 | 한 단계 | 최대 | 비용 (단계 n) |
|---|---|---|---|
| **시작 자본** | 시작 돈 +2.5 | 10단계 (+25) · 단, 시작 돈은 100을 넘지 않아요 | 3 + n |
| 공격력 | +4% | 5단계 (+20%) | 4 + 2n |
| 체력 | +4% | 5단계 (+20%) | 4 + 2n |
| 이동 속도 | +3% | 3단계 (+9%) | 3 + 2n |
- HP 회복은 넣지 않아요 (사용자 원문 규칙).
- 금고 화면은 시작 화면 → 나라 고르기 카드 안 "금고" 버튼 [제안].

## ③ 목표와 상한
- **30위 콜롬비아(14.6)**: 파산을 피하려면 시작 돈 37.6 이상 → 시작 자본 **10단계**(비용 합 85 — 4+5+…+13)가 필요해요.
  - 한 판 약 3 → 시작 자본이 오르면 더 멀리 가서 판당 5~8 → 대략 **15~20판**에 파산을 벗어나요. 그 뒤 6라운드를 깨려면 공격력·체력 몇 단계 더 → **약 20~25판** 예상 [시험 필요].
- **15위 한국**: 이미 파산은 안 해요 → 공격력·체력 2~3단계(약 5~8판)면 6라운드가 할 만해져요.
- **1위 룩셈부르크**: 시작 돈이 이미 100이라 시작 자본은 효과 없음. 공격력·체력만 최대 +20% → 너무 쉬워지지 않게 상한을 둬요.
- 수치는 QA가 봇으로 "판 수 → 클리어"를 재서 다듬어요.

## ④ 결말 문구와의 관계
- 파산 풍자 문구, 이어하기 "이런다고 없던 돈이 생길까?"는 **그대로**예요.
- 파산·실패 화면에 한 줄 더: **"금고에 +3 쌓였어요. 금고를 채우면 다시 도전할 수 있어요."** [제안]
- **2~30위가 금고 강화로 6라운드를 깨면** — 정해 주세요:
  - 가. **진짜 클리어 (추천)**: "클리어!" + 풍자 부제 **"출발선을 사는 데 N판 걸렸어요. 룩셈부르크는 1판이었어요."** — "모으면 결국 깬다"와 풍자가 같이 살아요.
  - 나. 지금처럼 "여기까지" 유지 (1위만 클리어) — 그러면 "결국 깬다"가 안 돼서 이번 결정의 이유와 맞지 않아요.

## ⑤ 저장
- 브라우저 저장(localStorage)에 나라별 금고·강화 단계를 저장해요.
- 포털 SDK 저장(Poki·CrazyGames·GameDistribution의 저장 기능 유무·방식)은 **출시팀 확인 필요**. 지워지면 다시 0이라는 안내를 설정 화면에 [제안].

## ⑥ 보상형 광고 "결과 2배" (사용자 미결정 · 별도 [제안])
- 판 끝 금고 정산 화면에 **[그냥 받기]**와 **[광고 보고 2배]**를 나란히 (그냥 받기 버튼이 작으면 안 돼요 — Gemini 정리 정책).
- 기존 규칙과 맞추기: 보상형·전면 광고는 겹치지 않음, 보상형 본 뒤 다음 전면 1번 건너뜀 (`monetization.md`).
- 위험: 2배가 있으면 하위권이 "광고로 출발선을 산다" → 풍자로는 맞지만 ("이런다고 없던 돈이 생길까?"와 같은 결), 심사에서 "돈 내야 이기는 구조"로 보일 수 있어요. → **한 판에 1번만**, 2배 상한 +5 [제안].

## 정해 주실 것
1. 나라별 금고(추천) / 공통 금고
2. 강화 4가지와 수치 (위 표) — 시험 뒤 다듬기
3. 금고로 깨면: 가. 진짜 클리어 + 풍자 부제(추천) / 나. "여기까지" 유지
4. 광고 "결과 2배": 넣기(한 판 1번) / 안 넣기
