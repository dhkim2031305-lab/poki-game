## 1. 한 줄 설명
- 지구에 외계인이 쳐들어와요. 같은 외계인, 같은 전장. 하지만 나라의 돈만큼 장수가 강하고, 싸울수록 돈이 줄어요. [제안]

## 2. 화면·조작
- 화면 방향: **가로** [제안] · 두 엄지로 잡기 편하고, 위에서 본 전장이 넓게 보여요.
- 폰: 화면 왼쪽 아래 가상 조이스틱, 오른쪽 아래 공격 버튼(크게) + 스킬 버튼 1개 [제안]
- PC: WASD/방향키 이동 · J 공격 · K 스킬 · 마우스 클릭도 공격으로 받아요 [제안]

## 3. 판 구성
```
나라 고르기 → 라운드 1 → (클리어) → 돈 줄어듦 → 라운드 2 → … → 라운드 6 클리어 = 게임 클리어
                 └─ 어느 라운드든 장수 HP 0 → 실패
```
- 라운드 길이 [제안]: 라운드마다 20~30초, 6라운드를 다 하면 약 2~3분이에요.
- 라운드 클리어 조건 [제안]: 그 라운드의 외계인을 모두 처치하면 클리어해요.
- 라운드 사이 [제안]: 2~3초 동안 "돈 −○○" 연출을 보여 줘요. 줄어든 돈과 약해진 능력치가 숫자로 보여요.

## 4. 돈 → 장수 능력치 [제안]

### ✅ 해석 확인 (원문 12번)
| 해석 | 맞나요? |
|---|---|
| **시작 돈**은 나라의 경제력 순위(OECD 1인당 GDP)로 정해져요 | ☑ (원문 14) |
| 라운드를 깰 때마다 돈이 줄고, **돈이 곧 장수의 강함**이에요 | ☑ (원문 14) |
| 그래서 약한 나라는 뒤 라운드로 갈수록 버티기가 아주 어려워져요 | ☑ (원문 14) |

### 돈이 줄어드는 방식 [제안]
- 팀장 세션 해석: **가. 비율로 줄기**예요. 사용자 답은 "상관없어"였어요. 다안(바닥값)을 더할지는 확정할 때 한 번 더 확인해요.
| 안 | 방식 | 결과 |
|---|---|---|
| 가. 비율로 줄기 | 라운드마다 남은 돈의 일정 비율이 줄어요 (예: −15%) | 모든 나라가 같은 비율로 약해져요. 격차는 처음 그대로예요 |
| 나. 같은 양으로 줄기 | 라운드마다 모든 나라에서 같은 금액이 빠져요 (예: −10) | 가난한 나라일수록 **비율로는 훨씬 크게** 줄어요. 뒤로 갈수록 격차가 벌어져요 |
| 다. 섞기 | 같은 양으로 줄이되, 최소한의 바닥값 아래로는 안 내려가요 | 나안의 메시지는 살리고, "클리어 불가는 없다"(원문 8번)도 지켜요 · **추천** |

### 돈이 영향을 주는 능력치 [제안]
| 능력치 | 돈이 많을수록 |
|---|---|
| 최대 HP | 높아요 |
| 공격력 | 세요 |
| 이동 속도 | 빨라요 |
| 스킬 쿨타임 | 짧아요 |

- 생김새는 모든 나라 장수가 같아요. 국기 색만 다르고, 능력치만 달라요.

### 정해 주실 것 — HP는 라운드 사이에 어떻게 되나요? [제안]
| 안 | 방식 |
|---|---|
| 가. 매 라운드 다시 꽉 채움 | 그 라운드의 돈 기준 최대 HP까지 채워요. 매 라운드가 새 판이라 이해하기 쉬워요 |
| 나. 이어짐 | 맞은 HP가 다음 라운드로 그대로 넘어가요. 훨씬 어려워져요 |

## 5. 나라 30개 [제안]
- OECD 회원국은 38개예요. 2026-11-24 oecd.org 검색 결과로 확인했고, 공식 페이지에서 다시 확인해요.
- 지표 [제안]: OECD Data Explorer의 1인당 GDP (구매력 기준), 가장 최근 확정 연도. 숫자는 출처를 확인한 뒤 넣어요.

### 38개 중 30개 고르는 법 — 하나를 골라 주세요 [제안]
| 안 | 방식 | 번역 언어 수 (대표 공용어 1개씩) |
|---|---|---|
| 가. 순위 고르게 | 경제력 순위 전체에서 고르게 빠지도록 8개를 빼요 | 약 20~23개 |
| 나. 번역 부담 적게 | 다른 나라와 언어를 같이 쓰지 않는 나라 위주로 8개를 빼요 | 약 17개 (가장 적어요) |
| 다. 38개 전부 | 처음부터 다 넣어요 | 약 25개 |

- 같이 쓰는 언어: 영어 6개국, 스페인어 5개국, 독일어 3개국, 프랑스어·네덜란드어 각 2개국
- 공용어가 여러 개인 벨기에·스위스·캐나다·룩셈부르크는 대표 언어를 하나 골라야 해요 [제안]

### 번역 작업량 [제안]
- UI 문구는 30줄 안팎이에요. 메뉴, 안내, 라운드 문구, 결과 문구가 들어가요. 그래서 17~25개 언어여도 글자 수는 많지 않아요.
- 검수: GPT로 1차 번역 → Gemini 역번역으로 뜻 대조 → 가능하면 원어민 확인
- 글꼴: 일본어·한국어는 글꼴 파일이 무거워요. 그래서 기기에 깔린 글꼴을 쓰고 ZIP 용량을 지켜요. 히브리어는 오른쪽에서 왼쪽으로 쓰니 화면 배치를 따로 확인해요.
- 원칙: 글자를 못 읽어도 플레이할 수 있게 버튼은 아이콘·색으로도 구분해요.

## 6. 한 판 흐름
```
시작 화면 → 나라 고르기(30개) → (UI가 그 나라 언어로 바뀜) → 라운드 1~6
→ 클리어 또는 실패 → 결과 화면 → (다시하기) → [광고] → 다시 플레이
```

## 7. 점수
- 깬 라운드 수 + 처치한 외계인 수. 최고 기록은 나라별로 저장해요 [제안]

## 8. 광고 위치
- 판 사이 광고: 다시하기를 누를 때
- 보상형 광고 [제안]: 장수가 쓰러졌을 때 광고를 보면 그 라운드부터 이어하기 1회 / 없음

## 9. 분위기·색감 (디자인팀 참고)
- 외계인: 도형 위주로 그리고, 형광 보라·초록처럼 우리 쪽과 확 구분되는 색을 써요 [제안]
- 장수: 같은 도형에 국기 색을 입혀요. 돈이 줄면 반짝임이 약해지는 정도로만 표현하고, 초라하게 그리지 않아요 [제안]
