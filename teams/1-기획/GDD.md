## 2. 화면·조작

## 4. 돈 → 장수 능력치 [제안·승인]

### ✅ 해석 확인 (원문 12번)
| 해석 | 맞나요? |
|---|---|
| **시작 돈**은 나라의 경제력 순위(OECD 1인당 GDP)로 정해져요 | ☑ (원문 14) |
| 라운드를 깰 때마다 돈이 줄고, **돈이 곧 장수의 강함**이에요 | ☑ (원문 14) |
| 그래서 약한 나라는 뒤 라운드로 갈수록 버티기가 아주 어려워져요 | ☑ (원문 14) |

### 돈이 줄어드는 방식 — ✅ 확정: 같은 양으로 줄기 (원문 15)
- 라운드를 깰 때마다 **모든 나라에서 같은 금액**이 빠져요. 바닥값은 없어요.
- 가난한 나라일수록 비율로는 훨씬 크게 줄어서, 뒤 라운드로 갈수록 격차가 벌어져요.
- 원문 8번("클리어 불가는 없음")을 지키는 조건이 있어요: **라운드당 감소량 × 5 < 최하위 나라 시작 돈.** 그래야 최하위 나라도 6라운드에서 돈이 0 이하로 내려가지 않아요. 자세한 건 `balance.draft.md`에 있어요.

### 돈이 영향을 주는 능력치 [제안·승인]
| 능력치 | 돈이 많을수록 |
|---|---|
| 최대 HP | 높아요 |
| 공격력 | 세요 |
| 이동 속도 | 빨라요 |
| 스킬 쿨타임 | 짧아요 |

- 생김새는 모든 나라 장수가 같아요. 국기 색만 다르고, 능력치만 달라요.

### HP — ✅ 확정: 매 라운드 꽉 채움 (원문 15)
- 라운드가 시작될 때 그 라운드의 돈 기준 최대 HP까지 채워요.

## 4-2. 아이템 (2026-11-24 추가 · 세부는 [제안], 사용자 확인 대기)
- 장수가 전장에 떨어진 아이템을 밟으면 먹어요.
- 종류 ✅ (사용자 "ㅇㅇ 넣어"): 분노(공격력 크게 오름, 8초), 방패(무적 5초), 구급상자(HP 50% 회복), 폭탄(화면 안 외계인 전부 공격), **금화(돈 +5, 넣기로 확정)**
- 등장 [제안]: 라운드마다 2개씩 나와요. **모든 나라에서 같은 아이템이 같은 위치, 같은 시간에 나와요** (같은 맵 규칙). 바닥에 10초 동안 있다가 사라져요.
- 효과 크기: **결정 필요** (아래 둘 중 하나)
  - 가. 나라와 상관없이 같은 크기예요. 분노는 "공격력 +20"처럼 정해진 값을 더해요. 약한 나라가 더 크게 덕을 봐서 역전할 기회가 생겨요.
  - 나. 돈에 비례해요. 분노는 "공격력 ×3"처럼 배로 늘려요. 원래 강한 나라가 더 강해져서 격차가 그대로 남아요.
- 수치는 `balance.md`에 있어요.

## 5. 나라 30개 [제안·승인]
- OECD 회원국은 38개예요. 2026-11-24 oecd.org 검색 결과로 확인했고, 공식 페이지에서 다시 확인해요.
- 지표 [제안·승인]: OECD Data Explorer의 1인당 GDP (구매력 기준), 가장 최근 확정 연도. 숫자는 출처를 확인한 뒤 넣어요.

### 38개 중 30개 고르는 법 — ✅ 확정: 가. 순위 고르게 (원문 15)
- 번역할 언어는 약 20~23개예요. 어느 8개국을 뺄지는 지표 숫자를 확인한 뒤 정하고, 사용자에게 보여 줘요.
| 안 | 방식 | 번역 언어 수 (대표 공용어 1개씩) |
|---|---|---|
| 가. 순위 고르게 | 경제력 순위 전체에서 고르게 빠지도록 8개를 빼요 | 약 20~23개 |
| 나. 번역 부담 적게 | 다른 나라와 언어를 같이 쓰지 않는 나라 위주로 8개를 빼요 | 약 17개 (가장 적어요) |
| 다. 38개 전부 | 처음부터 다 넣어요 | 약 25개 |

- 같이 쓰는 언어: 영어 6개국, 스페인어 5개국, 독일어 3개국, 프랑스어·네덜란드어 각 2개국
- 공용어가 여러 개인 벨기에·스위스·캐나다·룩셈부르크는 대표 언어를 하나 골라야 해요 [제안·승인]

### 번역 작업량 [제안·승인]
- UI 문구는 30줄 안팎이에요. 메뉴, 안내, 라운드 문구, 결과 문구가 들어가요. 그래서 17~25개 언어여도 글자 수는 많지 않아요.
- 검수: GPT로 1차 번역 → Gemini 역번역으로 뜻 대조 → 가능하면 원어민 확인
- 글꼴: 일본어·한국어는 글꼴 파일이 무거워요. 그래서 기기에 깔린 글꼴을 쓰고 ZIP 용량을 지켜요. 히브리어는 오른쪽에서 왼쪽으로 쓰니 화면 배치를 따로 확인해요.
- 원칙: 글자를 못 읽어도 플레이할 수 있게 버튼은 아이콘·색으로도 구분해요.
