# Gemini 아이디어 — 더 넣을 요소 (2026-11-27, 팀장 실행, gemini-3.8-flash 무료, 원문)

웹 게임 포털(**Poki, CrazyGames, GameDistribution, itch.io**)의 최신 트렌드와 개발자 가이드라인(Poki Developer Guidelines 등)을 기반으로 분석한 결과와 귀하의 2.5D 탑다운 액션 게임에 최적화된 기획안을 표로 정리해 드립니다.

---

### 🌐 [사전 조사] 요즘 웹 액션/로그라이트 포털의 핵심 트렌드 (2024~2026)
* **Bullet Heaven(Survivor/Brotato류)의 웹 안착:** 조작은 극도로 단순(이동+스킬 1~2개)하지만 빌드 조합이 깊은 게임이 포털 체류 시간 최상위권을 유지하고 있습니다.
* **영구 성장(Meta-Progression) 필수:** 한 번 죽으면 모든 게 끝나는 정통 로그라이크는 웹에서 이탈률이 매우 높습니다. 판당 3~5분이 끝나도 누적되는 재화/성장이 있어야 다음 날 재방문(D1 리텐션)이 발생합니다.
* **5초 룰(The 5-Second Rule):** 페이지 로드 후 5초 이내에 캐릭터를 직접 움직일 수 있어야 하며, 텍스트 튜토리얼을 읽게 만드는 순간 40% 이상의 유저가 탭을 닫습니다.
* **주스(Juice & Micro-engagement):** 화면 흔들림(Screen Shake), 타격 데미지 숫자, 동전 쏟아지는 소리 등 시각·청각 피드백이 강력해야 스트리머 바이럴과 포털 메인 피처링을 받습니다.

### ② 웹 포털에서 '첫 1분 이탈(Drop-off)'을 줄이는 요소

웹 유저는 설치 과정이 없기 때문에 마음에 안 들면 **클릭 한 번으로 3초 만에 이탈**합니다.

| 핵심 요소 | 구체적인 구현 방안 | 기대 효과 |
| :--- | :--- | :--- |
| **초고속 스타트 (5초 룰)** | 메인 화면에 30개 국기를 다 펼쳐놓지 말고, **[추천 강대국으로 즉시 전투]** 대형 버튼을 중앙에 배치 (국가 선택은 서브 버튼). 클릭 즉시 로딩 없이 전투 맵 진입. | 선택 장애(Decision Paralysis)로 인한 첫 화면 이탈 완전 차단. |
| **무텍스트 튜토리얼** | 텍스트 팝업창을 절대 띄우지 마십시오. 캐릭터 발밑에 키보드(WASD) 또는 모바일 가상 조이스틱 아이콘이 반투명하게 2초간 떴다가 첫 이동 시 페이드아웃. | 언어 장벽 없이 즉각적인 몰입 유도. |
| **첫 10초의 즉각적 쾌감** | 시작하자마자 체력이 낮은 외계인 3~5마리가 다가와 1~2방에 팡 터지며 반짝이는 코인이 쏟아지고 강렬한 타격음 발생. | "이 게임 타격감 좋다"는 인상을 10초 만에 각인. |
| **30초 내 첫 카드 선택** | 첫 번째 화폐 획득 및 카드 3장 선택 팝업이 **게임 시작 후 20~30초 이내**에 무조건 뜨도록 초기 요구 화폐량을 낮춤. | 게임의 핵심 루프(적 처치 ➔ 화폐 획득 ➔ 카드 선택 빌드업)를 1분 안에 체감. |
| **저용량 번들 & 스트리밍** | 18개국 보이스와 음악을 한꺼번에 프리로딩하지 말고, 선택된 국가의 리소스만 지연 로딩하여 초기 로딩 시간을 2~3초대로 단축 (CrazyGames 20MB, Poki 8MB 권장 기준). | 흰 화면 로딩 중 탭을 닫아버리는 이탈(Drop-off) 방지. |

### ③ 광고 수익 극대화 요소 (Poki/CrazyGames 정책 100% 준수)

Poki 등 메이저 포털은 **보상형 광고 가이드라인이 매우 엄격**합니다. 정책을 위반하면 검수에서 탈락하므로 반드시 규칙을 준수해야 합니다.

| 보상형 광고 위치 | 보상 내용 | 정책 준수 필수 사항 (Poki/CrazyGames 공통) |
| :--- | :--- | :--- |
| **1. 결과 화면: 국고 2배 정산**<br>*(최고 전환율)* | 게임 오버 시 획득한 영구 메타 재화를 2배로 수령 ("국고 지원금 200%"). | • **[그냥 받기] 버튼과 나란히 배치**해야 하며, 그냥 받기 버튼 크기가 광고 버튼보다 작으면 안 됨.<br>• 버튼에 반드시 비디오(▶) 아이콘 표시. |
| **2. 카드 선택 리롤 (Reroll)** | 레벨업 시 뜬 카드 3장이 마음에 들지 않을 때 1회 무료 새로고침. | • 광고 시청 중 **게임 완전 일시정지 및 BGM 음소거(Mute)**.<br>• 광고를 안 봐도 기존 카드 3장 중 하나를 골라 진행 가능해야 함. |
| **3. 긴급 파산 구제 (Revive)** | 사망 시 체력 50% 회복 + 2초 무적 부활 (판당 1회 제한). | • 카운트다운(5초)과 함께 [포기하기/재시작] 버튼이 명확히 제공되어야 함.<br>• **Poki 규정: 보상형 버튼에 '녹색(Green)' 사용 금지** (녹색은 일반 플레이 버튼 전용). 노랑/주황 권장. |
| **4. 게임 시작 시 '외국 원조'** | 시작 전 1티어 무작위 카드 1장 또는 보너스 초기 화폐를 받고 시작. | • 완전 선택형이어야 하며, 광고를 보지 않아도 바로 게임을 시작할 수 있는 기본 스타트 버튼이 상단에 있어야 함. |
| **전면 광고 (Interstitial)** | 라운드 종료 후 결과 화면으로 전환되는 자연스러운 시점에만 트리거. | • 플레이 중 갑자기 광고가 뜨면 정책 위반 및 즉시 이탈. 포털 SDK의 `gameplayStart()`와 `gameplayStop()` 타이머에 전적으로 맡길 것. |

1. **영구 메타 성장 시스템 (국가 금고 적립)**
   * **이유:** 웹 게임에서 "한 판 하고 끝나는 게임"과 "내일 다시 켜는 게임"을 가르는 유일한 차이점입니다. 하위권 국가로 억울하게 파산했더라도 "돈을 모아서 국고를 업그레이드하면 다음엔 4라운드까지 갈 수 있겠는데?"라는 재도전 동기를 부여해 게임의 수명을 10배 늘려줍니다.
2. **첫 60초 최적화 (대형 즉시시작 버튼 + 30초 내 첫 카드 선택 + 무텍스트 온보딩)**
   * **이유:** Poki와 CrazyGames 알고리즘은 **첫 3분 잔존율(Player Fit Test)**로 메인 노출 여부를 결정합니다. 초반 국가 선택에서 망설이게 하거나 튜토리얼 텍스트를 읽히는 순간 유저의 절반이 이탈합니다. 무조건 5초 안에 베어 넘기게 만들어야 합니다.
3. **Poki 규격 준수 '결과 2배' & '카드 리롤' 보상형 광고**
   * **이유:** 사망 시 부활 광고는 유저가 죽었을 때 기분이 상한 상태라 시청률이 20~30%에 불과합니다. 반면, "재화 2배"와 "원하는 빌드를 완성하기 위한 리롤"은 유저가 능동적으로 원해서 누르는 광고이므로 eCPM과 광고 시청 전환율이 가장 높아 실질적인 수익의 70% 이상을 견인합니다.
