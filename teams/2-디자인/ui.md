## 공통 규칙
- 터치 영역은 최소 44×44px. 조작 버튼은 그보다 훨씬 크게 해요.
- **가로 화면의 안전 영역**: 왼쪽·오른쪽 6%(노치·둥근 모서리), 위 5%(사이트 메뉴바)는 버튼을 두지 않아요.
- **글자를 못 읽어도 쓸 수 있게**: 모든 버튼은 아이콘이 주인공이고 글자는 보조예요. 시작 화면은 글자가 없어요.
- 화면 비율이 달라도: 전장은 **16:9로 고정**해서 가운데에 맞추고, 더 넓은 폰(19.5:9 등)은 양옆 남는 곳을 어둡게 채워요. 조작 버튼은 전장이 아니라 **화면 가장자리 기준**으로 놓아요.
- **폰을 세로로 들면**: "폰을 돌려 주세요" 화면(회전 아이콘만)을 보여 주고 게임을 멈춰요.
- PC: 같은 배치로 보여 주되, 화면 조이스틱·버튼은 **처음 터치가 들어올 때만** 보여요. 키보드 안내(WASD·J·K)는 첫 라운드 시작 3초 동안 아래에 작게 보여요.

## 광고 흐름 (CrazyGames 규칙: 판 사이 광고와 보상형 광고 버튼이 같은 때 뜨지 않게)
1. 실패·파산 화면에는 **보상형 광고 버튼만** 있어요. 이 화면에서는 판 사이 광고를 띄우지 않아요.
2. 보상형 버튼을 누르면 → 광고 → 바로 이어하기. 그 직후에도 판 사이 광고는 띄우지 않아요.
3. **다시하기 ↻**를 누르면 → 결과 화면이 닫힌 **다음에** 판 사이 광고 → 새 판.
4. 나라 바꾸기(깃발 두 개) → 광고 없음 (monetization.md).
- 보상형 광고 버튼 색 **확정** (사용자 "추천대로"): **어두운 바탕 + 금 테두리 + 영상 아이콘 + "AD" 배지**. 초록은 쓰지 않아요(Poki 규칙 대비).
- 파산 이어하기 (사용자 결정): 광고 보고 돈을 조금 받아 다음 라운드로 가요. **무제한**이에요. 버튼 글자는 "다음 라운드". 이어 가면 "이런다고 없던 돈이 생길까?"가 나와요.
