# UI — 초안 (draft v1)

> ⚠️ 승인 전 초안이에요. 기준 문서는 아직 `ui.md`예요.
> **기준 화면: 폰 가로 844×390** (GDD 2번 "가로" 확정). 위치는 화면 비율(%)로 적어요. (x, y)는 요소 가운데 기준이에요.
> 시안: `teams/2-디자인/preview/index.html`

## 공통 규칙
- 터치 영역은 최소 44×44px. 조작 버튼은 그보다 훨씬 크게 해요.
- **가로 화면의 안전 영역**: 왼쪽·오른쪽 6%(노치·둥근 모서리), 위 5%(사이트 메뉴바)는 버튼을 두지 않아요.
- **글자를 못 읽어도 쓸 수 있게**: 모든 버튼은 아이콘이 주인공이고 글자는 보조예요. 시작 화면은 글자가 없어요.
- 화면 비율이 달라도: 전장은 **16:9로 고정**해서 가운데에 맞추고, 더 넓은 폰(19.5:9 등)은 양옆 남는 곳을 어둡게 채워요. 조작 버튼은 전장이 아니라 **화면 가장자리 기준**으로 놓아요.
- **폰을 세로로 들면**: "폰을 돌려 주세요" 화면(회전 아이콘만)을 보여 주고 게임을 멈춰요.
- PC: 같은 배치로 보여 주되, 화면 조이스틱·버튼은 **처음 터치가 들어올 때만** 보여요. 키보드 안내(WASD·J·K)는 첫 라운드 시작 3초 동안 아래에 작게 보여요.
