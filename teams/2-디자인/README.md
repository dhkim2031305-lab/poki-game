# 디자인팀

## 파트
| 파트 | 하는 일 | 문서 |
|---|---|---|
| UI | 시작·플레이·결과 화면, 버튼, 글자 | `ui.md` |
| 오브젝트·이펙트 | 플레이어, 장애물, 색, 파티클, 흔들림 | `style-guide.md` |
| 사운드 | 효과음, 배경음 | `sound.md` |

## 맡는 일
- 확정된 기획서를 보고 **스타일 가이드(`style-guide.md`)**를 써요. 색, 도형, 글꼴, 효과, 소리 느낌까지 정해요.
- 기본은 **에셋 없이 도형·색·파티클로** 그려요. 용량이 작고 로딩이 빨라야 해요.
- 이미지가 꼭 필요하면 GPT로 만들고, Claude가 크기를 확인해 줄인 뒤 `src/assets/`에 넣어요.

## 산출물
- `ui.md`, `style-guide.md`, `sound.md`
- 시안 미리보기 (스크린샷이나 아티팩트)
- (필요하면) `src/assets/` 이미지·소리
