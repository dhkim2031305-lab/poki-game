# 사운드 — 초안 (draft v1)

> ⚠️ 승인 전 초안이에요. 기준 문서는 아직 `sound.md`예요.
> 기본은 Web Audio로 코드가 직접 만드는 소리 (파일 0KB). 소리 크기는 전체 기준 0~1.
> 시안 페이지(`teams/2-디자인/preview/index.html`)에서 버튼을 눌러 직접 들어볼 수 있어요.

| 상황 | 느낌 | 방식 | 길이 | 음높이·파형 | 크기 |
|---|---|---|---|---|---|
| 공격 | 가벼운 "뿅" | 코드 | 60ms | square 880→660Hz | 0.12 (자주 나니 작게) |
| 외계인 맞음 | 짧은 "틱" | 코드 | 40ms | 잡음(noise) + 높은 통과 필터 2kHz | 0.15 |
| 외계인 처치 | 통통 "팝" + 지글 | 코드 | 140ms | triangle 520→120Hz + 잡음 80ms | 0.25 |
| 장수 맞음 | 낮고 둔한 "퍽" | 코드 | 200ms | sawtooth 180→70Hz, 낮은 통과 필터 800Hz | 0.35 |
| 스킬 | 위로 쓸어 올리는 "슈웅" | 코드 | 300ms | sine 200→900Hz + 잡음 휘감기 | 0.3 |
| 라운드 클리어 | 밝은 3음 | 코드 | 420ms | triangle C5·E5·G5 (각 120ms) | 0.3 |
| 돈 감소 | 동전 "짤랑" 2음 내려감, **담담하게** | 코드 | 동전 1개당 90ms × 3~5 | sine 1320→990Hz, 짧은 울림 | 0.2 |
| 게임 클리어 | 짧은 팡파르 | 코드 | 1s | square+triangle C5·E5·G5·C6 + 화음 | 0.35 |
| 실패(쓰러짐) | 부드럽게 내려가는 3음 | 코드 | 700ms | sine G4·E4·C4, 천천히 작아짐 | 0.25 |
| 최고 기록 갱신 | 반짝 2음 올라감 | 코드 | 300ms | sine E6·B6 | 0.25 |
| 버튼 누름 | 작은 "틱" | 코드 | 20ms | sine 1000Hz | 0.1 |
| 이어하기(광고 후) | 다시 일어나는 상승음 | 코드 | 500ms | triangle 300→800Hz | 0.3 |
| 배경음 | `[결정 필요]` 넣음(제안) | 코드 | 8마디 반복 (120bpm, 약 16초) | 베이스 triangle + 낮은 pulse 리듬, 라운드가 오를수록 드럼만 조금 빨라짐 | 0.12 |

## 규칙
- 광고 중엔 모든 소리 끔 (개발팀이 처리)
- 첫 탭 전에는 소리 안 남 (브라우저 정책)
- **음소거 버튼: 넣음** `[결정 필요]` · 시작 화면 오른쪽 위 + 일시정지 메뉴. 설정은 저장해요.
- 같은 소리가 한꺼번에 여러 번 나면(외계인 여러 마리 동시 처치) **최대 4개까지만** 겹쳐요.
- 돈 감소·실패 소리는 슬프거나 놀리는 느낌이 나지 않게, 짧고 담담하게 만들어요 (GDD ⚠️ 비하 방지).
- 파일 0KB예요. 나중에 파일을 쓰게 되면 `src/assets/`에 .mp3/.ogg, 개당 100KB 이하.
