1. 시작 화면 나라를 고르기 전이라 글자 없이 아이콘만 써요

2. 나라 고르기 30개 카드는 모두 같은 모양이에요 · 이름은 그 나라 언어로 써요

시안의 국기는 간단히 그린 그림이에요. 실제 게임에서는 정확한 SVG 국기 파일을 쓰자고 제안해요(아래 질문 1).

3. 플레이 화면 왼손 조이스틱 · 오른손 공격(크게)과 스킬

전장은 16:9로 고정해서 가운데에 둬요. 화면이 더 넓은 폰에서는 양옆이 어두운 띠가 돼요. 조이스틱과 버튼은 화면 가장자리 기준으로 놓아요. 공격은 원거리라고 임시로 정해서 그렸어요.

4. 라운드 사이 (2~3초) 돈이 줄고, 능력치 막대가 줄어요

5. 결과 화면 왼쪽: 실패(이어하기 광고 있음) · 오른쪽: 클리어

6. 돈에 따른 장수 모습 모양·크기는 같고, 금빛 반짝임만 달라요

돈이 가장 적어도 반짝임은 사라지지 않아요. 낡거나 초라한 표현은 쓰지 않아요(GDD ⚠️ 비하 방지).

정해 주셔야 할 것

  • 1. 국기 그리는 방법 · 제안: 공개 라이선스 SVG 국기 30개를 써요. 약 100~150KB예요. 코드로 직접 그리면 용량은 0이지만 캐나다·미국·멕시코 국기처럼 복잡한 건 틀리기 쉬워요.
  • 2. 배경음 · 제안: 코드로 만든 짧은 반복음을 넣고, 음소거 버튼도 넣어요.
  • 3. 흔들림 끄기 버튼 · 제안: 일시정지 메뉴에 넣어요.
  • 기획팀 확인 필요 · 게임 제목, 공격 방식(근접/원거리), 스킬 내용이 GDD에 없어요. 시안에는 임시로 넣었어요(원거리 공격, 주변 충격파).
