# 사운드 (디자인팀 · 사운드 파트)

> 기본은 Web Audio로 코드가 직접 만드는 소리 (파일 0KB). 파일이 필요하면 `src/assets/`에 .mp3/.ogg로, 개당 100KB 이하.
> 상태: **GDD 확정 후 작성**

| 상황 | 느낌 | 방식 (코드/파일) | 길이 | 음높이·파형 |
|---|---|---|---|---|
| 탭/점프 | | | | |
| 점수 획득 | | | | |
| 죽음 | | | | |
| 최고 기록 갱신 | | | | |
| 배경음 | (없음 / 있음) | | | |

## 규칙
- 광고 중엔 모든 소리 끔 (개발팀이 처리)
- 첫 탭 전에는 소리 안 남 (브라우저 정책)
- 음소거 버튼: (넣음 / 안 넣음)
